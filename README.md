# Analog Clock

Simple Python desktop apps built with Tkinter.

## Analog clock

```bash
python3 analog_clock.py
```

## Snake II (Nokia 3310 style)

```bash
python3 snake_game.py
```

- **2 / 4 / 6 / 8** or arrow keys — move
- **5** or **Space** — start / pause / restart
- **\*** or **Escape** — back to title

Tkinter ships with most Python installations. If your system Python does not include it,
install the Tk package for your operating system and run the command again.
